shimashima-121

The tile repeats every 600 px across and 900 px down. Scroll to look for a seam.
To use it, copy the image files beside the page and put this in its style:
body {
    background: #285077 url('shimashima-121.webp') repeat;   /* #285077 shows at once, while the picture loads */
    background-image: image-set(url('shimashima-121.avif') type('image/avif') 1x, url('shimashima-121@2x.avif') type('image/avif') 2x, url('shimashima-121.webp') type('image/webp') 1x);
    background-size: 600px;
}
