The chess engine for the Analysis and the robots on the chess page: Stockfish 19, as compiled for the web by Stockfish.js (the lite, single-threaded build).

It runs in each visitor's own browser, in a Web Worker. Nothing it works out is sent anywhere.

- Stockfish.js: https://github.com/nmrugg/stockfish.js (npm package `stockfish` 19.0.1, files `bin/stockfish-19-lite-single.js` and `.wasm`, unchanged)
- Stockfish: https://github.com/official-stockfish/Stockfish
