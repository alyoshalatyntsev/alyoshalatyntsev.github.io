Help

Draw

Drag for a straight line or freehand stroke. For a path or curve, click successive points. Double-click the last point, press Escape, or press Enter to finish.

Curves pass smoothly through the points. Select a curve to move its points and tangent handles. Hold Ctrl/⌘ while dragging a tangent to adjust one side independently.

Select

Click an object, drag a selection rectangle, or use the lasso. Shift-click adds or removes objects. Drag a selected object to move the selection. A drawn path is one object; template pieces are separate objects.

Crossings

Shift starts a line underneath existing lines. Select a line to show crossing-related lines in red. Use the crossing tool to swap an individual overpass. The gap menu sets clearance; shallow intersections and region textures remain intact.

Fill & colour

The bucket fills closed outlines or existing regions. Choose a pattern and fill colour in the top bar. Click the line or fill colour chip to choose which colour the palette changes. Right-click a swatch to set the fill colour.

Files & TikZ

Save a project to keep editable curves and crossing settings. SVG and PNG export with transparency. TikZ requires \usetikzlibrary{patterns,arrows.meta}. Enter LaTeX labels as text; they render in LaTeX output.
