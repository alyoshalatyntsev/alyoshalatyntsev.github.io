Help

Draw

Drag for a straight line or freehand stroke. For a path or curve, click successive points. Double-click the last point, press Escape, or press Enter to finish.

Curves pass smoothly through the points. Use the white arrow to drag points and tangent handles; the black arrow moves whole objects. Hold Ctrl/⌘ while dragging a tangent to adjust one side independently.

Select

Click an object, drag a selection rectangle, or use the lasso. Shift-click adds or removes objects. Drag a selected object to move the selection. A drawn path is one object; template pieces are separate objects.

Templates & groups

Choose a template, then click the canvas to place it. Escape cancels; Shift places it underneath. Dragging from the strip also works. Colours and stroke settings update the previews and new pieces. Use ‹ / › or the < / > keys to scroll the strip.

Select pieces and press Ctrl/⌘ G to move them together. Ctrl/⌘ Shift G ungroups them. The white arrow edits individual points inside a group. Groups are saved in project files.

The Back–Front slider under Arrange changes the stack position of selected lines. Region fills remain behind the strings. Changing a line's order resets its individual crossing overrides.

Regions & dots

For a curved region, click boundary points and finish with Escape, Enter, or a double-click. Drag the handles to reshape it. Click the dot tool to place a 2pt dot; drag its radius handle to resize it.

Snapping

The grid − / + buttons beside zoom set the spacing in centimetres. Click the spacing readout to return to 1 cm. The grid magnet snaps to grid points. The node magnet snaps to path anchors and dot centres; a blue ring marks the target. Node snapping takes priority when both are on.

Crossings

Shift starts a line underneath existing lines. Select a line to show crossing-related lines in red. Use the crossing tool to swap an individual overpass. The gap menu sets clearance; shallow intersections and region textures remain intact.

Fill & colour

The bucket fills closed outlines or existing regions. Choose a pattern and fill colour in the top bar. Click the Line or Fill colour chip to choose which colour the palette changes. Right-click a swatch to set the fill colour.

Files & TikZ

Each visit starts blank. Load shows previews of the last 20 nonempty drawings saved in this browser. New and Open keep the current drawing there before switching. Save downloads a project for keeping elsewhere.

Save a project to keep editable curves and crossing settings. SVG and PNG export with transparency. Copy the Preamble box into your LaTeX preamble and the diagram into the document. Coordinates use centimetres; weights and text sizes use points. Standard colours use TikZ names. Enter LaTeX labels as text; they render in LaTeX output.

Edit the diagram code, then click Apply or press Ctrl/⌘ Enter to update the canvas. Undo reverses the edit. The editor supports its exported TikZ commands and reports unsupported commands; it does not run a full LaTeX compiler.
